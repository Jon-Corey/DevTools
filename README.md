# DevTools

DevTools is a collection of tools and resources for developers. The tools are built to be simple to use and run fully on your own device so that your data stays private.

Check it out at [DevTools.JonCorey.Dev](https://devtools.joncorey.dev/).

![The DevTools logo followed by text reading 'Simple, Free, Private'.](/src/assets/images/card.svg)

## Key Features

- A collection of useful tools all in one place
- Each tool receives special attention to make it as simple to use and useful as possible
- Mobile-friendly design
- Free with no usage limits
